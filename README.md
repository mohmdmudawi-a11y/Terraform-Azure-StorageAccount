# Terraform Azure Storage Account

## Overview

This project demonstrates deploying an Azure Storage Account using Terraform Infrastructure as Code.

## Resources Created

- Azure Resource Group
- Azure Storage Account

## Technologies

- Microsoft Azure
- Terraform
- Infrastructure as Code

## Deployment

Initialize Terraform:

```bash
terraform init
```

Validate configuration:

```bash
terraform validate
```

Create execution plan:

```bash
terraform plan
```

Deploy:

```bash
terraform apply
```

Remove resources:

```bash
terraform destroy
```
